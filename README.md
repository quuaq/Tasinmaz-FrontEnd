## 🏢 TasinmazFrontEnd (Taşınmaz Bilgi Sistemi - Ön Yüz / Front-End)

---

## 🌐 English

A modern and responsive front-end application for the Real Estate Information System, developed with Angular.  
Users can list, search, and manage properties; view and update details; and access an admin panel for property/user management.  
This project is designed for municipal or enterprise property management use.

## ✅ Technologies Used
- Angular 19.2
- TypeScript
- Bootstrap / SCSS
- RESTful API integration

## ⚙️ Features
- Property listing
- Detail view and edit
- User authentication (login/register)
- Admin panel for property and user management
- Seeing the location of the property on the map

---

## 🇹🇷 Türkçe

Angular ile geliştirilmiş, modern ve duyarlı bir Taşınmaz Bilgi Sistemi ön yüz uygulaması.  
Kullanıcılar taşınmazları listeleyebilir, arama ve filtreleme yapabilir, detaylarını görüntüleyip düzenleyebilir, ayrıca admin paneli üzerinden taşınmaz ve kullanıcı yönetimi gerçekleştirebilir.  
Bu proje, belediye veya kurumlar için taşınmaz yönetimi amacıyla tasarlanmıştır.

## ✅ Kullanılan  Teknolojiler
- Angular 19.2
- TypeScript
- Bootstrap / SCSS
- RESTful API integration

 ## ⚙️ Features
- Taşınmaz listeleme
- Detail view and edit
- Kullanıcı kimlik doğrulama (giriş/kayıt)
- Taşınmaz ve kullanıcı yönetimi için admin paneli
- Harita üzerinden taşınmazın konumu görme
